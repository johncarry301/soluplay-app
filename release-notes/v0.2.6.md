SoluPlay 0.2.6 — the channel number steps out of the way, a lost signal looks like one, and an update that has been downloaded now reaches the installer on the phone.

## Fixed

- **Channel number:** the number in the top right corner now hides after ten
  seconds. It comes back when the channel changes and stays up while a number
  is being typed on the remote.
- **Lost signal:** the rolling static is gone. A channel with no working
  mirror now shows a broken satellite dish with the caption "No signal", so
  a lost signal is told apart from a channel that is merely tuning.
- **Installing an update on the phone:** the downloaded build was handed to
  the system's installer, but the app never opened the confirmation screen
  the installer asked for, so nothing appeared to install. The confirmation
  is now opened as soon as the installer asks for it, and the result is
  reported back to the sheet.
- **Returning from the permission screen:** after allowing the app to install
  packages, the app now carries on and installs the build it already
  downloaded instead of leaving the sheet on a button that only reopened the
  settings screen.

## Not changed

- The signing key, the application id (`com.soluplay.app`), the Android TV
  launcher, minSdk 21 and targetSdk 34 are unchanged.
