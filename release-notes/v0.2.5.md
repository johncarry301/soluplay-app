SoluPlay 0.2.5 — the television remote gets the keys viewers expect, and a channel that fails once is tried again instead of going straight to static.

## Improved

- **Channel list:** the lit row stays in the middle of the list and moves in a
  single step per key press, so holding the remote no longer stutters. The
  focused row is marked with a bright band and an edge strip, readable from
  across the room.
- **Tuning:** while a channel is being tuned, its logo and name stand in the
  middle of the screen with the travelling edge line, so the viewer can see
  what is being tuned.
- **Channel number:** the channel's place in the list is shown at the top
  right corner of the screen.
- **Number keys:** typing a channel number on the remote tunes that channel
  (for example 1 then 2 tunes channel 12); the number appears at the corner
  as it is typed.
- **CH+ / CH-:** CH+ now plays the next channel down the list and CH- the one
  before it. The old mapping walked the list backwards.
- **Mirror order on TV:** the television tries the plain HTTP mirrors before
  the secure ones, because an old TV certificate store can refuse an HTTPS
  mirror that the same channel plays over HTTP. The phone keeps the site's
  order.
- **First attempt:** if a channel's mirror list cannot be read the first time,
  it is asked for again a moment later instead of leaving the screen on the
  static until the viewer leaves the channel and comes back.

## Not changed

- The signing key, the application id (`com.soluplay.app`), the Android TV
  launcher, minSdk 21 and targetSdk 34 are unchanged.
